# Инструкции для агента

## Изменение кода

Перед изменением исходного или тестового кода сначала покажи пользователю предлагаемый diff и кратко объясни ожидаемый результат. Затем запроси явное согласие на внесение изменений. Применяй diff только после согласия пользователя; до этого выполняй лишь чтение и проверки, не меняющие код.

## Ревью

По запросу `review` проведи ревью изменений в этом репозитории по правилам из [pipelines/review.md](pipelines/review.md). Сначала прочитай этот файл целиком. Если пользователь уточнил область ревью, проверяй её; иначе проверяй текущие изменения относительно `HEAD`, включая добавленные файлы.

При ревью не меняй код, если пользователь отдельно не попросил об исправлениях.
